# Flores Amarillas 🌻💛

Una experiencia web interactiva, romántica y con estética de acuarela en papel artesanal, dedicada con todo el amor de **Leonardo** para **Lisa Mari**.

Inspirada en el amor, Snoopy, los girasoles y la canción tradicional de *Flores Amarillas* (Floricienta).

---

## ✨ Características

1. **Portada Romántica**: Snoopy admirando los girasoles, corazones enlazados con las iniciales de Leonardo y Lisa Mari, y botón para abrir el regalo.
2. **Ramo de Flores Amarillas**: Ramo interactivo en acuarela que florece con destellos y confeti al tocarlo.
3. **El Sobre Sellado**: Snoopy Noted y sobre vintage con sello de girasol que se abre con sonido y animación de papel.
4. **La Carta de Amor**: Mensaje íntimo y conmovedor, fotografía polaroid del 21 de Septiembre y deseos desde el corazón.
5. **Jardín Mágico de Flores Animadas**: Al pulsar *"¡Lluvia de flores animadas!"*, se abre un jardín nocturno con flores que crecen y florecen bajo un cielo estrellado con estrellas fugaces, luciérnagas doradas y las letras sincronizadas de la canción.
6. **Música Continua**: La canción *"Flores Amarillas"* suena a lo largo de toda la experiencia sin pausas.

## 🛠️ Instalación y Uso

```bash
# Instalar dependencias
pnpm install

# Iniciar servidor de desarrollo
pnpm dev

# Compilar para producción
pnpm build
```
